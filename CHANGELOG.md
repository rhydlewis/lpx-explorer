# Changelog

All notable changes to LPX Explorer are documented here. The CI release
pipeline extracts each `## v<version>` section into the `<description>`
field of the appcast, which Sparkle renders in the update dialog.

Format: standard Markdown — `-` bullets and free-form paragraphs.
Headings within a section (`###`) are not currently extracted.
