# 2026-05-05 — AU lookup v1 spec (epic `lpx-explorer-59o`)

**Status:** draft, awaiting bead-filing pass
**Inputs:** chat 2026-05-05, `docs/specs/2026-05-04-ux-design-v1.md`, `docs/decisions.md` (entries 2026-05-04 #1 + #2), `lpx-toolkit/lpx_inspect.py` (parse_auval_line, auval_lookup), `lpx-toolkit/CLAUDE.md` (auval quirks).
**Out of scope:** action-on-finding (deferred); user-renamed track names (`qib` / `5d8.cluster`); AU bundle inspection (auval -a — explicitly avoided per Python tool's CLAUDE.md, segfaults on broken installs).

## Summary

Resolve project plug-in fingerprints (`aumu/EZk2/Toon`) into human-readable names ("EZdrummer 2") and cross-reference each against the user's installed AU registry to drive the `<CompatibilityVerdict>` pill colour and per-row install-status badges in `<PluginList>`. The registry is built by parsing `auval -l` output in Rust, cached to `~/.cache/lpx-explorer/auval.json`, and loaded once per session into a new `useAuRegistryStore`.

## Decisions (resolved 2026-05-05)

1. **Cache location:** `~/.cache/lpx-explorer/auval.json` only. **Do not** share or fall back to `~/.cache/lpx-toolkit/auval.json` — keeps tool boundaries clean. Users with the Python tool installed run their own scan in `lpx-explorer`.
2. **"Run AU scan" CTA placement:** inline next to the verdict pill in `<CompatibilityVerdict>`. Most contextual; the user is looking at "AU registry not yet scanned" and the action lives right there.
3. **Auval invocation:** stream via `Channel<AuvalEvent>`, mirroring `scan_folder`'s pattern (bead `has.6`). Live count of plug-ins discovered. Survives partial output if `auval` segfaults mid-scan (see `lpx-toolkit/CLAUDE.md` auval quirks).
4. **Phantom-plugin grouping:** done in TypeScript at the `<PluginList>` level via `useMemo`. Rust output stays as-is so per-track inserts (`Track.instrument`/`midi_fx`/`audio_fx`) keep their individual `AURef` identity.
5. **IPC shape:** separate `load_au_registry()` + `run_au_scan()` commands. Registry loaded once per session into a new `useAuRegistryStore`; `parse_project` stays untouched.

## IPC shape

### Rust (`lpx-parser` + `commands.rs`)

```rust
// crates/lpx-parser/src/auval.rs
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct AuvalEntry {
    pub fingerprint: String,        // "aumu/EZk2/Toon"
    pub type_4cc: String,           // "aumu"
    pub subtype_4cc: String,        // "EZk2"  (preserve trailing/leading spaces verbatim)
    pub manufacturer_4cc: String,   // "Toon"
    pub name: String,               // "EZdrummer 2"
}

/// Parse one line of `auval -l`. Returns `None` for header / blank /
/// malformed lines. Column-offset based — does NOT split on whitespace
/// (manufacturer 4CCs can contain spaces, e.g. "kHs ", "EB  ").
pub fn parse_auval_line(line: &str) -> Option<AuvalEntry>;

#[derive(Debug, Clone, Serialize)]
#[serde(tag = "type")]
pub enum AuvalEvent {
    Entry(AuvalEntry),
    Done,
}
```

```rust
// src-tauri/src/auval.rs

/// Read & parse cache from ~/.cache/lpx-explorer/auval.json.
/// Returns Ok(None) when the cache file does not exist.
#[tauri::command]
pub fn load_au_registry() -> Result<Option<AuRegistry>, AuvalError>;

/// Spawn `auval -l`, stream each parsed entry via `on_event`, write
/// the full registry to ~/.cache/lpx-explorer/auval.json on completion,
/// emit `AuvalEvent::Done` last.
#[tauri::command]
pub async fn run_au_scan(on_event: Channel<AuvalEvent>) -> Result<(), AuvalError>;

#[derive(Debug, Serialize)]
pub struct AuRegistry {
    pub entries: Vec<AuvalEntry>,
    pub scanned_at_unix: i64,    // when this cache was written
}

#[derive(Debug, Error, Serialize)]
#[serde(tag = "kind", content = "message")]
pub enum AuvalError {
    SpawnFailed(String),         // could not exec auval
    CacheRead(String),           // cache file unreadable
    CacheParse(String),          // cache file present but corrupt JSON
    CacheWrite(String),          // could not write cache
}
```

## State

New store: `src/store/au-registry-store.ts`.

```ts
type RegistryStatus =
  | { kind: "idle" }                  // never loaded this session
  | { kind: "loading" }                // load_au_registry() in flight
  | { kind: "absent" }                 // cache file doesn't exist; user can run scan
  | { kind: "scanning"; found: number } // live count from Channel events
  | { kind: "loaded"; registry: AuRegistry }
  | { kind: "error"; message: string };

interface AuRegistryState {
  status: RegistryStatus;
  loadFromCache: () => Promise<void>;   // called once on App mount
  runScan: () => Promise<void>;          // triggered by the CTA
  byFingerprint: () => Map<string, AuvalEntry>;  // memoised lookup
}
```

`App` calls `useAuRegistryStore.getState().loadFromCache()` once on mount.
`<CompatibilityVerdict>` reads `status` + the loaded project's fingerprints
to compute the verdict.

## Render strategy

### `<CompatibilityVerdict>`

Reads `useProjectStore.current.summary.fingerprints` + `useAuRegistryStore.status`.

Status mapping:

| Registry status | Project fingerprints     | Verdict       | Pill colour |
|-----------------|--------------------------|---------------|-------------|
| `loaded`        | all installed             | "Opens cleanly" | green |
| `loaded`        | some missing             | "{N} plug-ins missing" | amber |
| `loaded`        | all missing              | "Will not open" | red |
| `loaded`        | project has zero plug-ins | "Opens cleanly — no plug-ins to check" | green |
| `absent`        | any                       | "AU registry not yet scanned" + **Run AU scan** button | neutral grey |
| `scanning`      | any                       | "Scanning installed AUs… ({found})" | neutral grey |
| `loading` / `idle` | any                    | "AU registry not yet scanned" | neutral grey |
| `error`         | any                       | "AU scan failed: {message}" + **Try again** | neutral grey |

The CTA is a small accent-blue button placed right of the pill (or below on narrow widths). Click → `useAuRegistryStore.getState().runScan()`. Disabled while `scanning`.

### `<PluginList>`

Reads `summary.fingerprints` + `useAuRegistryStore.status`. Renders the existing list **plus**:

1. **Group identical fingerprints** via `useMemo`: `[{ fingerprint, count, first_offset }]`. `count > 1` shows a `×N` badge after the row.
2. **Resolve names** from the registry when `status.kind === "loaded"`:
   - Render: `EZdrummer 2  ×3   aumu/EZk2/Toon  • Installed`
   - Or for missing: `aumu/Unkn/Mfgr  ×1  • Missing on this Mac` (red badge)
3. **Install-status badge** per row: green `Installed`, red `Missing`, neutral grey when registry isn't loaded.

Section heading + aria-label stay `plug-ins`. Empty state ("No plug-ins detected.") unchanged.

## Acceptance criteria (testable)

- [ ] `parse_auval_line` parses each documented quirk: trailing-space subtype (`EB  ` for EchoBoy), leading-space manufacturer (`kHs ` for Kilohearts), hyphenated plug-in names (`EZ-Drummer`), header line returns `None`.
- [ ] `parse_auval_line` does NOT split on whitespace — column offsets `[0:4]`, `[5:9]`, `[10:14]` per `lpx_inspect.py:789-796`.
- [ ] `load_au_registry()` returns `Ok(None)` when the cache file doesn't exist (no error).
- [ ] `load_au_registry()` returns `Err(CacheParse)` when the cache exists but is corrupt JSON.
- [ ] `run_au_scan()` writes valid JSON to `~/.cache/lpx-explorer/auval.json` on success.
- [ ] `run_au_scan()` emits one `AuvalEvent::Entry` per discovered AU, then `AuvalEvent::Done`. Cargo integration test: spawn a fake `auval` script that emits 3 lines, assert 3+1 events arrive.
- [ ] `useAuRegistryStore` starts `idle`, transitions to `loading` → `loaded` (or `absent`) on `loadFromCache()`.
- [ ] `runScan()` transitions `idle/absent → scanning(found: N) → loaded`. `found` increments per `Entry` event.
- [ ] `<CompatibilityVerdict>` renders the **green** "Opens cleanly" pill when registry is loaded and every project fingerprint has a matching entry.
- [ ] `<CompatibilityVerdict>` renders **amber** "{N} plug-ins missing" when some fingerprints are missing; missing count matches the project's missing fingerprints.
- [ ] `<CompatibilityVerdict>` renders **red** "Will not open" when ALL project fingerprints are missing.
- [ ] `<CompatibilityVerdict>` renders **neutral** grey + a "Run AU scan" button when registry status is `absent`. Click → `runScan()`.
- [ ] `<CompatibilityVerdict>` renders the live count "Scanning installed AUs… (47)" while scanning.
- [ ] `<PluginList>` groups identical fingerprints with a `×N` badge when N > 1.
- [ ] `<PluginList>` renders the registry-resolved name when registry is loaded; falls back to the raw fingerprint otherwise.
- [ ] `<PluginList>` per-row install-status badge: green "Installed", red "Missing on this Mac", neutral grey when registry isn't loaded.
- [ ] No `any` types or type assertions. All fixtures use `makeAuRegistry()` + `makeSummary()`.
- [ ] `cargo test --workspace` and `npm run quality` both green.
- [ ] Read-only invariant test (`crates/lpx-parser/tests/readonly_invariant.rs`) still passes — `parse_auval_line` takes `&str`, the Tauri command writes only to `~/.cache/lpx-explorer/`, never to a `.logicx`.

## Edge cases

1. **`auval -l` segfaults mid-scan.** The spawned process exits with non-zero before emitting `Done`. The store's `scanning` status flips to `error("auval crashed at N entries")`. Whatever entries we received are discarded (don't write a partial cache to disk — could mislead a later session). User can retry; the documented fix in `lpx-toolkit/CLAUDE.md` is to repair the broken plug-in install before retrying.
2. **Cache file from a previous version with extra/missing fields.** `load_au_registry` deserializes via serde; unknown fields are ignored, missing required fields → `CacheParse`. User clicks "Run AU scan" to regenerate.
3. **Project has zero fingerprints.** `<CompatibilityVerdict>` reads "Opens cleanly — no plug-ins to check" (green) when the registry is loaded; "AU registry not yet scanned" otherwise. The "no plug-ins to check" copy avoids implying the project is empty.
4. **Phantom plug-ins (per `lpx-toolkit/CLAUDE.md`).** A project showing 3 identical `aumf/FXR /SToy` fingerprints renders one `<PluginList>` row with `×3` and a single install-status badge. The TS grouping doesn't deduplicate based on offset — it uses the fingerprint string only. Track-level inserts (`Track.midi_fx`) still show all 3 individually since each is on a real (or phantom) track.
5. **Registry has stale entries (user uninstalled a plug-in since last scan).** The cache reports it as installed, the user sees green, but Logic would error on open. Acceptable for v1: cache invalidation is a future concern. The `scanned_at_unix` field surfaces in the Inspector's CompatibilityVerdict tooltip ("Scanned 5 days ago — Run again") so the user has agency.
6. **`auval` returns no entries (fresh macOS install with no third-party AUs).** Apple's built-in AUs show up; the registry loads with the Apple defaults. Project-side missing fingerprints amber/red as expected.
7. **CTA clicked twice rapidly.** `runScan()` checks status — if `scanning`, return early. Idempotent.

## Open questions worth re-resolving later

1. **Cache invalidation.** v1 doesn't auto-invalidate. Worth a UX trigger when `Components/` mtime changes, but defer until cache staleness is reported as a problem.
2. **Per-AU error during scan (a single line failing to parse).** v1 silently drops malformed lines. Counting + reporting parse failures is a v1.1 polish item.
3. **Cross-platform.** macOS-only per the brief; `auval` is macOS-specific. No Linux/Windows fallback in scope.
